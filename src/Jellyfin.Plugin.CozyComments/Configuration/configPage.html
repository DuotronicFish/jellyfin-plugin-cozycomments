Cozy Comments

Changes apply without restarting Jellyfin. Users see them the next time they load or refresh the web app. Requires the File Transformation plugin. Documentation: see the project README.

Comments page
A page with everyone's newest comments, opened from a card in "My Media" on the home screen. Turn off to remove both. Comments on movie and show pages are not affected.
